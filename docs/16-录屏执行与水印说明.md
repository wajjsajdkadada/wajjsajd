## 三、水印添加说明

### 3.1 水印内容规范（课设常见要求）

| 项 | 建议值 |
|---|---|
| 内容 | `学号 姓名` 或 `班级-学号-姓名` |
| 位置 | **右下角**（不与组件/按钮重叠）；或全屏斜向重复 |
| 透明度 | 30%–40%（能看清但不挡内容） |
| 字号 | 视频宽度的 3%（1080p 约 32px） |
| 颜色 | 白色 + 黑色描边（深浅背景都能看清） |
| 是否移动 | 建议**固定**，避免被判为后期合成 |

### 3.2 方法一：剪映（推荐，最简单）

1. 导入录屏 → 拖到时间轴；
2. 顶部「文字」→「新建文本」→ 输入 `2023001 张三`；
3. 右侧「样式」：字号 8、颜色白、描边黑 2px、不透明度 40%；
4. 拖到画面右下角，时长拉到与视频一致；
5. 右上角「导出」：1080p / 30fps / 码率「推荐」。

> 剪映的「文本」会默认居中，记得手动拖到右下并检查是否压到按钮。

### 3.3 方法二：FFmpeg（可批量、可自动化）

```bash
# 单个视频加右下角水印（文字）
ffmpeg -i input.mp4 ^
  -vf "drawtext=text='2023001 张三':fontfile='C\:/Windows/Fonts/msyh.ttc':fontcolor=white@0.4:fontsize=32:x=w-tw-30:y=h-th-30:borderw=2:bordercolor=black@0.5" ^
  -c:v libx264 -crf 20 -preset medium -c:a copy ^
  output_watermarked.mp4
```

```bash
# 全屏斜向重复水印（更强的防伪效果）
ffmpeg -i input.mp4 -vf ^
  "drawtext=text='2023001 张三':fontfile='C\:/Windows/Fonts/msyh.ttc':fontcolor=white@0.25:fontsize=28:x=(w-tw)/2:y=(h-th)/2:borderw=1:bordercolor=black@0.3" ^
  -c:v libx264 -crf 20 output_tiled.mp4
```

> Windows 下 `fontfile` 的路径里冒号要转义成 `\:`，正斜杠也要转义 `\/`；
> 更省事的写法是把字体文件复制到当前目录，直接用 `fontfile=msyh.ttc`。

### 3.4 画中画水印（另一种常见做法）

把「学号姓名」做成一张透明 PNG（如 400×120），然后用：

```bash
ffmpeg -i input.mp4 -i watermark.png -filter_complex ^
  "[1]format=rgba,colorchannelmixer=aa=0.35[wm];[0][wm]overlay=W-w-30:H-h-30" ^
  -c:v libx264 -crf 20 output.mp4
```

### 3.5 导出参数（交给老师前的最后一步）

| 参数 | 值 |
|---|---|
| 分辨率 | 1080×1920（竖屏）或 1920×1080（若投屏演示） |
| 帧率 | 30 fps |
| 码率 | 4–6 Mbps（H.264） |
| 音频 | 若有旁白，AAC 128kbps |
| 文件命名 | `学号-姓名-主App演示.mp4` / `学号-姓名-小组件演示.mp4` |
| 总时长 | 各 ≤ 3:00（超时可能被扣分） |

## 四、常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 点了「已复习」数字没变 | App 进程被杀，组件走冷启动 | 先打开一次 App 再回桌面 |
| 录制里出现别的 App 通知 | 未开勿扰 | 录制前下拉打开勿扰模式 |
| 翻牌动画录不到 | 录屏帧率低 | 帧率调到 60fps，或点击后停留 1 秒 |
| 组件数字与 App 不一致 | 手动改过系统时间 | 关掉自动时间再复原，或重启 App |
| 视频文件过大 | 码率太高 | 用 CRF 23 重新编码，或上传前压缩 |
