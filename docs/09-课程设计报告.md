# 课程设计报告（初稿）

**项目**：单词记忆 App（B4 主 App + P1 桌面小组件伴生模块）
**版本**：v1.0（第 15 阶段产出，对应提交 #15）
**说明**：本报告是**汇总稿**，各章节的细节分别落在 `docs/01`~`docs/08`，报告正文只保留答辩需要的骨架与关键结论。

---

## 1. 项目概述

### 1.1 一句话

一个纯离线的单词记忆 App：导入词库 → 自研「艾宾浩斯-Δ」算法排出每日复习队列 → 桌面小组件随时显示还剩多少词、支持一键过词。

### 1.2 交付形态

| 单元 | 模块 | 说明 |
|---|---|---|
| B4 主 App | `:app` | 5 个界面（列表/详情/复习/导入/设置）+ 算法参数页 |
| P1 伴生模块 | `:widget` | 2×2 桌面小组件：今日待复习数 + 一键「已复习」 |
| 数据层 | `:core-data` | Room 8 张表、Repository、导入解析器、队列引擎 |
| 领域层 | `:core-domain` | 艾宾浩斯调度器（纯 Kotlin，零 Android 依赖） |

### 1.3 技术栈（**实际使用**，与早期设计有差异）

| 层 | 选型 |
|---|---|
| 语言 | Kotlin 2.3.21（AGP 9 内置 Kotlin，不再单独 apply 插件） |
| UI | **View 体系 + RecyclerView**（早期方案为 Compose，已变更，见 §9） |
| 状态 | ViewModel + StateFlow + sealed interface 全状态渲染 |
| 数据 | Room 2.8.5（KSP 注解处理）+ Flow 响应式查询 |
| 异步 | Coroutines |
| 后台 | WorkManager 2.9.1（每日提醒、小组件跨天刷新） |
| 组件 | AppWidget + RemoteViews |
| 构建 | Gradle 9.6.0 / AGP 9.4.0 / compileSdk 37 / minSdk 26 |

## 3. 系统设计

### 3.1 分层

```
UI 层（:app）        Activity + ViewModel + StateFlow
      │ 只依赖领域接口
数据层（:core-data）  Repository / Room / 导入解析 / 队列引擎
      │
领域层（:core-domain）艾宾浩斯调度器 / 领域模型 / 仓库契约（零 Android 依赖）
```

### 3.2 模块依赖（实际）

```
:app ──► :widget ──► :core-data ──► :core-domain
 │                        ▲
 └────────────────────────┘
```

- `:widget` 不引用 `:app` 任何类（点击跳转用显式类名字符串常量）；
- `:app → :widget` 是打包必需：library 的 manifest 只有被 app 依赖才会合并进 APK。

### 3.3 数据流（单向）

```
用户操作 → ViewModel.onXxx() → Repository（suspend）
        → Room 写入 → Flow 发射变化 → UiState 重组 → 界面刷新
```

界面**不持有可变状态**，也不手动刷新列表。

### 3.4 界面与状态机

| 界面 | 状态 |
|---|---|
| 单词列表 | Loading / 无词库 / 词库空 / 筛选无结果 / Error / Content |
| 单词详情 | Loading / NotFound / Error / Content（历史空为子态） |
| 复习页 | Loading / NoDue / Error / Answering（正面/背面）/ Finished |
| 导入页 | IDLE / READY / IMPORTING / DONE / ERROR |
| 算法参数 | 正常 / 保存失败 |

## 4. 数据库设计

### 4.1 表清单（8 张）

| 表 | 职责 | 关键约束 |
|---|---|---|
| `wordbook` | 词库 | `archived_at` 非空 = 已归档（不删数据） |
| `word` | 单词 | 联合唯一 `(book_id, spelling_lower)` |
| `review_state` | 记忆状态（1:1） | 主键 = `word_id`，索引 `next_due_at` |
| `review_log` | 复习流水（只增） | 索引 `(word_id, reviewed_at)`、`reviewed_at` |
| `import_record` | 导入记录 | 失败明细 JSON（≤100 条） |
| `setting` | 键值配置 | `algo.*` 前缀存算法参数 |
| `review_session` | 复习会话（v2） | 唯一 `date_key`（一天一会话） |
| `queue_item` | 队列项（v2） | 唯一 `(session_id, word_id)` |

### 4.2 三个关键设计决策

1. **`spelling_lower` 列**：SQLite 的 `COLLATE NOCASE` 只处理 ASCII，Room 也无法在 `@Index` 声明 collation → 显式小写列，一个联合唯一索引同时支撑去重、字母排序、前缀搜索；
2. **`review_log.interval_ms` 而非 `next_due_at`**：存间隔可复现算法决策，不受时区/系统时间篡改影响；
3. **归档而非删除**：`archived_at` 只改一列，单词/状态/流水全保留 → 删词库不影响统计。

### 4.3 迁移

v1 → v2 新增两张队列表，用**手写 Migration**（建表语句与 Room 生成的 `schemas/2.json` 逐字一致），并保持 `fallbackToDestructiveMigration` 关闭——不清用户数据。

### 4.4 事务边界

| 操作 | 事务内容 |
|---|---|
| 导入（每 200 行） | upsert word + 初始化 review_state |
| 作答 | 更新 review_state + 写 review_log + 出队 + 会话计数（四写原子） |
| 彻底删除词库 | 外键 CASCADE 级联清除 |

## 5. 关键实现

### 5.1 CSV 导入（手写解析器）

- 状态机处理引号包裹、字段内换行、`""` 转义、BOM、`,`/`;`/`\t` 自动识别；
- **错误精确到物理行号**（"第 47 行：meaning 列为空"）——这是不用 opencsv 的核心原因；
- 严格 UTF-8 解码（`CodingErrorAction.REPORT`），GBK 文件在解码阶段即中止并提示另存；
- 流式解析 + 每 200 行一个事务：5 万行不 OOM，取消时已提交批次保留。

### 5.2 复习队列引擎

- 优先级下推 SQL：`next_due_at ASC → lapse_count DESC → stage ASC → id ASC`；
- 队列持久化：`review_session` + `queue_item`，重启后恢复同一批未作答词；
- **重开机制**：当天会话完成后又有新到期词 → 重开会话追加队列项（避免 `date_key` 唯一索引冲突）。

### 5.3 艾宾浩斯-Δ 算法

| 反馈 | 阶段 | 难度系数 | 间隔 |
|---|---|---|---|
| 不认识 | −2（≥0） | −0.20 | 新阶段基础值 |
| 模糊 | 不变 | −0.05 | 减半（≥10min） |
| 认识 | +1 | +0.05 | 基础值 × ease/2.5 |
| 熟练 | +2（≤9） | +0.10 | 同上 |

- 阶段表：5min / 30min / 12h / 1d / 2d / 4d / 7d / 15d / 30d / 60d；
- `mod = ease / 2.5` **仅 stage ≥ 2 生效**（分钟级不放大）；抖动 ±5% **仅 stage ≥ 4**；
- 间隔夹取 5min ~ 180d；掌握 = `stage ≥ 8 且遗忘 ≤ 2`。

### 5.4 小组件与数据同步

- 同进程共享 Room 单例 → 不需要 ContentProvider/AIDL；
- 四条刷新链路：系统 onUpdate（30min 兜底）/ App 启动 / **写库后 `WidgetSync.notifyDataChanged()` 实时** / WorkManager 每日 00:05 跨天归零；
- 快捷「已复习」复用队列引擎 `answer(RECALLED)`，保证 `review_log` 与会话计数一致。

### 5.5 权限降级与异常兜底

| 权限 | 用途 | 拒绝后 |
|---|---|---|
| `POST_NOTIFICATIONS` | 每日提醒 | 提示「用桌面小组件替代」+ 去设置 |
| `READ_EXTERNAL_STORAGE`（≤API32） | 下载目录直读 | 降级为手动添加单词 |
| 存储权限（主导入） | — | **不申请**，用 SAF |

崩溃兜底：`Thread.setDefaultUncaughtExceptionHandler` 写 `crash.log` + 下次启动提示，不自动重启（避免掩盖问题）。

## 8. 问题与改进

详见 `docs/08`。最典型的两个：

1. **当天复习完再来新词导致崩溃**（`date_key` 唯一索引冲突）→ 改为重开会话追加；
2. **AGP 9 的破坏性变更**：Android 模块不得再 apply `kotlin-android`（Kotlin 已内置），
   且 `android.defaults.buildfeatures.buildconfig` 已移除——这两个都是构建期直接报错，改后才通。
