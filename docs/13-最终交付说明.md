## 5. 开发文档 PDF 导出规范

### 5.1 格式要求

| 项 | 要求 |
|---|---|
| 纸张 | A4，纵向 |
| 页边距 | 上下 2.5cm，左右 2.5cm（左侧可 3cm 便于装订） |
| 正文 | 宋体 / 思源宋体 **小四（12pt）**，行距 1.5 倍 |
| 标题 | 一级 黑体 三号（16pt）居中；二级 黑体 四号（14pt）；三级 黑体 小四加粗 |
| 代码块 | 等宽字体（Consolas / JetBrains Mono）**五号（10.5pt）**，浅灰底 `#F5F5F5`，加 1pt 左边框 |
| 页码 | 页脚居中，阿拉伯数字，从正文第 1 页开始 |
| 目录 | 自动生成，含二级标题，单独成页 |
| 图题 | 图 X-Y 图名，居中，五号宋体，图下 |
| 表题 | 表 X-Y 表名，居中，五号宋体，表上（三线表） |
| 封面 | 学校模板（校名/课设名称/题目/姓名/学号/班级/指导教师/日期） |

### 5.2 导出步骤（推荐 WPS / Word）

1. 用 **Typora / VS Code + Markdown PDF 插件**把 `09-课程设计报告.md` 转成 DOCX；
   或直接复制到 WPS 里套用「正文-中文论文」样式；
2. 粘贴封面模板 → 插入自动目录 → 全选正文设置字体与行距；
3. 把 `docs/01~08` 的对应章节**按 §4.1 的对应关系**并入报告（不要整篇粘贴，避免重复）；
4. **导出前检查三点**：① 目录页码与正文一致；② 所有图片不跨页断裂；③ 代码块不出现横向滚动条（长行手动折行）；
5. `文件 → 导出为 PDF`，勾选「嵌入字体」，文件名：`学号-姓名-单词记忆App-课程设计报告.pdf`。

### 5.3 PDF 自检清单

- [ ] 封面信息完整、无错字
- [ ] 目录页码正确
- [ ] 图表均有编号与标题
- [ ] 代码块字体为等宽、有底纹
- [ ] 无不含中文字体的乱码（尤其代码注释）
- [ ] 总页数 ≥ 20 页（课设常见下限）
- [ ] 文件大小 < 20 MB
