# 界面原型说明（4 个核心页面）

**文档版本**：v1.0（第 2 阶段产出，对应提交 #2）
**表达方式**：线框 + 控件规格表 + 状态矩阵。线框用等宽字符绘制，可直接贴进课设报告；第 4 阶段落地为 Compose 组件。
**不做的部分**：不在本阶段出高保真视觉稿（Figma/Sketch）。课设验收看的是「界面完整、状态齐全、交互闭环」，线框 + 规格已能唯一确定实现，视觉细节交给 Material3 默认主题。

---

## 0. 与界面清单的对应关系

`docs/02` 现定义 **5 个界面**（UI-1~UI-5）。原「词库列表」页已按评审意见取消：词库**切换**并入 UI-1 标题栏下拉，词库**管理**并入 UI-5。本文档覆盖全部 5 个界面，其中 §2~§5 是你要求的 4 个核心页面：

| 本文档章节 | 页面 | 对应 UI 编号 | 说明 |
|---|---|---|---|
| §2 | 单词列表 | UI-1 `WordListScreen` | **首页**，标题栏含词库切换器 |
| §3 | 单词详情 | UI-2 `WordDetailScreen` | 浏览路径叶子 |
| §4 | 复习页 | UI-3 `ReviewQueueScreen` | 学习路径核心 |
| §5 | 导入 / 设置 | UI-4 `ImportScreen` + UI-5 `SettingsScreen` | 支撑路径，设置页含词库管理 |

## 1. 全局设计规范

所有页面共用一套 token，禁止在页面里写魔法值。

| 类别 | 规范 | 说明 |
|---|---|---|
| 间距 | 8dp 基准栅格：4 / 8 / 12 / 16 / 24 / 32 | 页面左右内边距统一 16dp |
| 圆角 | 卡片 12dp、按钮 12dp、Chip 8dp、弹窗 24dp | 统一 `MaterialTheme.shapes` |
| 字体 | 页面标题 20sp/600、正文 14sp/400、辅助 12sp/400、单词大字 36–40sp/600 | 不硬编码 `sp`，走 `MaterialTheme.typography` 扩展 |
| 颜色 | 全部取自 `ColorScheme`：`primary` 主按钮、`surfaceVariant` 卡片底、`error` 忘记、`tertiary` 提示 | 深色模式自动跟随，无硬编码色值 |
| 四档反馈色 | 忘记 `#D9534F`、模糊 `#E8A33D`、想起 `#3B82F6`、熟练 `#2E9E5B` | 仅在 `Color.kt` 定义一次，深色模式降一档亮度 |
| 图标 | Material Symbols Rounded | `material-icons-extended` |
| 动效 | 翻牌 300ms、页面切换 Material3 默认、进度条 200ms | 不做花哨动画，答辩时不抢戏 |
| 触控区 | ≥ 48dp | 复习页四档按钮实测 56dp 高 |

## 2. 页面一：单词列表 `WordListScreen`

### 2.1 目标与入口

- **目标**：**首页**。在某个词库内快速找到某个词，或看清「哪些词今天该复习」；「切换词库」与「找到词」都在这一屏完成，不额外设一层词库列表。
- **入口**：App 启动直接进入（默认打开上次的词库；首次为内置示例词库）。
- **出口**：点条目 → 单词详情。**本页无返回箭头**（它是根），按返回键 = 退出 App。

### 2.2 线框


### 2.3 控件规格

| 编号 | 控件 | 类型 | 尺寸/字号 | 文案或内容 | 交互 |
|---|---|---|---|---|---|
| ① | 词库切换器 + 更多 | `TopAppBar` | 高 64dp；标题 20sp + `▾` | 标题＝当前词库名，超长省略 | 点标题弹词库下拉（全部未归档词库 + 各词库到期数 + 「新建词库…」）；⋮ 菜单：导入到本词库 / 管理词库（跳设置页并定位到词库管理） |
| ② | 搜索框 | `SearchBar`（折叠） | 高 48dp，圆角 24dp | 占位「搜索单词…」 | 输入防抖 300ms 触发查询；空结果态见 §2.4 |
| ③ | 统计条 | `Text` | 12sp，`onSurfaceVariant` | `共 {total} 词 · 今日到期 {due}` | 点击「今日到期 32」→ 直接跳复习页 |
| ④ | 排序 Chip | `FilterChip` ×3 | 高 32dp | 到期优先 / A-Z / 最新 | 单选；切换即重查（默认「到期优先」） |
| ⑤⑥⑦ | 列表项 | `ListItem` | 高 72dp，左内边距 16dp | 第 1 行：拼写 18sp/600 + 右侧状态徽章<br>第 2 行：音标 12sp<br>第 3 行：释义 14sp 单行省略 | 整项可点 → 详情；长按 → 快捷菜单（标记已掌握 / 重置进度） |

**状态徽章规则**：到期 `●`（`tertiary` 色）；已掌握 `✓`（绿色）；普通 `·`（灰色小点）。

### 2.4 状态矩阵

| 状态 | 渲染 |
|---|---|
| Loading | 8 行骨架（灰块 3 行仿列表项），不显示进度圈 |
| Empty（无任何词库） | 居中 +「还没有词库」+ 主按钮「新建词库」（弹出输入框）+ 次按钮「导入」 |
| Empty（词库无词） | 居中插画位 +「这个词库还没有单词」+ 主按钮「导入词库」 |
| Empty（搜索无结果） | 居中 +「没有匹配「abandon」的单词」+ 文字按钮「清空搜索」 |
| Error（查询失败） | 居中 +「加载失败」+「重试」按钮（`error` 色图标） |
| Success | 列表（`LazyColumn`，稳定 `key = word.id`） |
| 删除中 | 该行显示 50% 透明 + 右侧小进度圈 |

## 3. 页面二：单词详情 `WordDetailScreen`

### 3.1 目标与入口

- **目标**：看清一个词的四要素，并理解「系统为什么现在让我复习它」（调度透明化，答辩加分项）。
- **入口**：单词列表点条目；复习页点「查看详情」。
- **出口**：返回上一页（返回栈保持）。

### 3.2 线框

### 3.3 控件规格

| 编号 | 控件 | 类型 | 规格 | 说明 |
|---|---|---|---|---|
| ① | 标题栏 | `TopAppBar` | 高 64dp | ⋮ 菜单：复制单词、删除该词 |
| ② | 拼写 | `Text` | 36sp/600，可长按选择复制 | 超长（>16 字符）自动降到 28sp |
| ③ | 音标 + 状态 Chip | `Text` + `AssistChip` | 音标 14sp 灰；Chip 高 24dp | Chip 文案三态：待复习 / 已掌握 / 新词（`reviewCount=0`） |
| ④ | 释义卡 | `ElevatedCard` | 内边距 16dp，圆角 12dp | 多行自动换行，最多显示 6 行后「展开」 |
| ⑤⑥ | 例句卡 | `ElevatedCard` | 同上 | 无例句时显示「暂无例句」（灰斜体），不隐藏整卡 |
| ⑦ | 四宫格 | 4 × `Column` | 每格宽自适应，数字 20sp/600，标签 12sp | 见下方取数规则 |
| ⑧ | 阶段进度条 | `LinearProgressIndicator` | 高 8dp，圆角 4dp | 进度＝`stage / 9` |
| ⑨ | 历史时间线 | `LazyColumn`（内嵌，最大高 240dp） | 每项高 56dp，左侧圆点连线 | 默认显示最近 5 条 |
| ⑩ | 展开入口 | `TextButton` | 14sp | 点击加载全部（分页 20 条/次） |
| ⑪ | 底部操作条 | `BottomAppBar` | 高 72dp，`surface` 底 | 两个等宽按钮，见交互 |

**四宫格取数**：阶段＝`stage/9`；难度＝`easeFactor` 保留两位；到期＝相对时间（「2 天后」/「今天」「已过期 3 小时」）；遗忘＝`lapseCount`。

### 3.4 状态矩阵

| 状态 | 渲染 |
|---|---|
| Loading | 单卡片骨架（标题块 + 3 个内容块） |
| Error | 「加载失败」+ 重试 |
| 词已被删除（如从别处删了） | Snackbar「该单词已被删除」+ 自动返回上一页 |
| Success | 完整详情 |
| 历史为空 | 历史区显示「还没有复习记录」（不隐藏区块） |

### 3.5 交互

| 操作 | 行为 |
|---|---|
| 点「标记已掌握」 | 直接把 `stage` 置 8、`isMastered=true`、`nextDueAt` 按 30 天算；按钮变为「取消掌握」；Snackbar 可撤销（5s） |
| 点「重置进度」 | 二次确认弹窗「该词将回到新词状态，复习记录保留」→ 确认后 `stage=0, ease=2.50, lapse=0, nextDueAt=now` |
| 长按拼写 | 复制到剪贴板 + Toast |

## 4. 页面三：复习页 `ReviewQueueScreen`

### 4.1 目标与入口

- **目标**：一屏一词、翻牌作答、即时结算。**这是全 App 使用时长最长的页面，交互必须零歧义。**
- **入口**：单词列表统计条「今日到期 32」；**桌面小组件**（深链 `dancijiyi://review`）；每日提醒通知。
- **出口**：答完 → 完成页；✕ → 二次确认「还有 12 词未复习，确定退出？」→ 回主页。

### 4.5 控件规格与关键规则

| 编号 | 控件 | 规格 | 关键行为 |
|---|---|---|---|
| ① | 进度条 + 计数 | 高 6dp；计数 14sp | `已答/总数`；进度以「已作答」而非「进入过」计 |
| ② | 单词 | 40sp/600，超长降 32sp | 单行，超长缩字号，不换行（保持卡片比例） |
| ③ | 音标 | 16sp，`onSurfaceVariant` | 缺音标则不占位（布局重心下移） |
| ④ | 揭示提示 | 20sp，带呼吸动画（alpha 0.4↔1.0，1200ms） | 点击卡片任意处触发翻牌 |
| ⑤ | 四档按钮 | 每个：宽均分、高 56dp、圆角 12dp、文字 16sp/600 | **未揭示时禁用**：`enabled=false` + 30% 透明 + 点击弹 Snackbar「先看释义再评价」 |
| ⑥ | 跳过 / 撤销 | 文字按钮 14sp | 跳过＝不计入作答、移出本次队列；撤销＝回滚上一题的 `reviewState` 与 `reviewLog`，最多撤销 1 步 |
| ⑦ | 释义 | 22sp/500 | 多行，最多 4 行后省略 |
| ⑧ | 例句 | 14sp + 译文 13sp 灰 | 无例句则整段隐藏 |
| ⑨ | 上下文提示 | 12sp，`surfaceVariant` 底胶囊 | 新词 / 第 N 次复习 · 距上次 X；让用户知道系统为什么现在问 |
| ⑩–⑮ | 完成页组件 | 见线框 | 正确率＝(想起+熟练)/作答数；平均用时来自 `durationMs` |

**答题节奏约定**：点击四档按钮后**立即结算并滑入下一词**（无二次确认、无动画等待），结算动画 ≤ 200ms。撤销窗口只在「进入下一词后 3s 内」有效。

### 4.6 状态矩阵（本页最复杂，共 7 态）

| 状态 | 渲染 |
|---|---|
| Loading（队列生成中） | 卡片骨架 +「正在准备今日队列…」 |
| Empty-无词库 | 「还没有词库」+ 主按钮「去导入」 |
| Empty-今日已清空 | 「今日复习已完成 🎉」+「明日约 28 词」+ 「返回主页」 |
| Error | 「队列加载失败」+ 重试 |
| Success-作答中 | 卡片 + 四档按钮 |
| Success-完成 | 完成页 |
| 上限顺延提示 | 首次进入时顶部 Snackbar：「今日上限 50 词，另有 12 词顺延到明日」 |

### 5.4 导入页 · 控件与规则

| 编号 | 控件 | 规格 | 规则 |
|---|---|---|---|
| ① | 关闭 | `TopAppBar` 无返回箭头，用 ✕ | 有进度时点 ✕ → 确认「导入未完成，取消将丢弃已导入部分？」（已提交批次保留） |
| ② | 目标词库下拉 | `ExposedDropdownMenu` | 默认上次使用的词库；无词库时禁用并提示先建词库 |
| ③ | 文件选择区 | 虚线边框 `OutlinedCard`，高 200dp，整体可点 | 走 SAF `ACTION_OPEN_DOCUMENT`（**不申请存储权限**）；`mimeType = */*`，靠扩展名与内容嗅探区分 CSV/JSON |
| ④ | 模板下载 | `TextButton` | 从 assets 拷出 `template.csv` 到 SAF 指定目录（`ACTION_CREATE_DOCUMENT`） |
| ⑤–⑥ | 文件信息 / 统计 | 14sp / 12sp | 解析在 IO 线程流式进行，仅读表头 + 逐行计数，不整体入内存 |
| ⑦ | 失败明细 | 可折叠，最大高 200dp 滚动 | 每条＝`第 N 行：原因`；超过 100 条只显示前 100 条 +「仅显示前 100 条」 |
| ⑧ | 开始导入 | 主按钮，宽 100%，高 52dp | 可导入数为 0 时禁用 |
| ⑨–⑩ | 进度 / 取消 | `LinearProgressIndicator` + 文字按钮 | 每 200 行一个事务；取消后已完成批次保留，结果页标注「已取消」 |
| ⑪ | 四类统计 | 4 宫格 | 新增 / 更新（同词拼写已存在）/ 跳过（空行）/ 失败（校验不过） |
| ⑫ | 后续动作 | 主按钮 + 次按钮 | 「去背单词」→ 复习页 |

### 5.6 设置页 · 控件与降级规则

| 编号 | 控件 | 默认值 | 边界 / 降级 |
|---|---|---|---|
| ① | 提醒开关 | 关 | 开启时先检查 `POST_NOTIFICATIONS`（API 33+）：无权限 → 开关回弹为关 + 显示 ③ 提示 |

| ③ | 降级说明行 | — | 仅在权限缺失时出现（`error` 色小字 + 「去设置」跳系统页）；有权限时整行隐藏 |
| ④ | 每日上限滑块 | 50 | 范围 20–200，步进 10；实时显示当前值；改动即时写库 |

| ⑥ | 词库列表项 | — | 每项显示「名称 · 词数 · 到期数」；已归档项置灰并带「已归档」徽章。点击弹操作单：重命名 / 归档 / 恢复 / 彻底删除 |
| ⑦ | 新建词库 | — | 弹输入框；名称 trim 后非空且 ≤32 字符；创建后自动切换到该词库 |
| ⑧ | 统计区 | — | 从 `review_log` 聚合，**包含已归档词库**（归档不丢统计）；无数据显示「暂无数据」 |

| ⑩ | 清空所有数据 | — | 二次确认 + 需输入「确认」二字（破坏性操作加强确认） |
| ⑪ | 版本 / 算法标识 | — | 来自 `BuildConfig.VERSION_NAME` + 算法常量 |
