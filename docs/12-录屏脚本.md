# 录屏脚本（主 App 3 分钟 + 伴生模块 3 分钟）

**录制准备**：真机或模拟器、已安装最新 APK、桌面已放好小组件、录屏 1080p / 60fps、关掉通知栏其他干扰。
**旁白风格**：先"我在做什么"，再"为什么这么做"，不要念代码。

---

## 一、主 App 录屏脚本（3:00）

| 时间 | 画面操作 | 旁白 |
|---|---|---|
| 0:00-0:10 | 桌面 → 点 App 图标启动 | 「这是我的单词记忆 App。整个应用是纯离线的，不联网也能用。」 |
| 0:10-0:30 | 停留在单词列表，滑动几下 | 「首页直接是单词列表，上面能看到"共 12 词 · 今日到期 12"。没有多余的层级。」 |
| 0:30-0:50 | 点搜索框输入 `ab`，再清空；点「今日到期」筛选 | 「支持前缀搜索，输入即筛；也支持按"今日到期/新词/已掌握"分组筛选，筛选条件是在 SQL 层做的，不是内存过滤。」 |
| 0:50-1:10 | 点 `abandon` 进详情 | 「详情页有四要素，还有记忆状态四宫格——阶段、难度系数、到期时间、遗忘次数。这一块是给用户解释"系统为什么现在考我这个词"。」 |
| 1:10-1:20 | 返回 → 点「导入词库（CSV）」→「用示例文件」→ 开始导入 | 「导入走系统文件选择器，**不申请存储权限**，这样少一条权限被拒的降级路径。」 |
| 1:20-1:35 | 结果页展示「新增 6」；点「再导一个」再导一次 | 「同一个文件再导一次，变成"更新 6、新增 0"——去重靠数据库的 `(词库, 小写拼写)` 联合唯一索引。」 |
| 1:35-2:10 | 返回首页 → 点「开始复习」 | 「进入复习页。**没翻牌时三个按钮是灰的**，必须先看释义再评价，防止瞎点污染调度数据。」 |
| 2:10-2:25 | 点卡片翻牌 → 点「不认识」→ 下一个词 → 点「认识」 | 「四个反馈里我用三档：不认识让阶段回退两档，模糊原地加固，认识推进一档，难度系数同步调整。」 |
| 2:25-2:45 | 连续答完 → 结算页 | 「结算页给出答对率、平均耗时，还有三档分布条。这个会话已经写进数据库，杀进程也不会丢。」 |
| 2:45-2:55 | 点「算法参数」→ 拖动每日上限 → 保存 | 「算法参数可配：每日上限、间隔抖动开关。改完立即生效，不用重启。」 |
| 2:55-3:00 | 回到桌面（留住画面） | 「主 App 到这里，接下来看桌面小组件。」 |

## 二、伴生模块录屏脚本（3:00）

| 时间 | 画面操作 | 旁白 |
|---|---|---|
| 0:00-0:10 | 停留在桌面，组件居中 | 「这是 P1 伴生模块——桌面小组件，它显示今日待复习数量。」 |
| 0:10-0:25 | 长按空白 → 小组件 → 拖入新的一个 | 「从系统小组件列表添加，尺寸是 2×2，可以拉伸。」 |
| 0:25-0:45 | 指一下数字与「下一个：abandon」 | 「数字和 App 里完全一致——因为组件和 App 是**同一个进程、同一个 Room 实例、同一份数据库文件**，不存在两套数据。」 |
| 0:45-1:05 | 点「已复习」按钮 → 数字减 1 | 「组件上可以直接标记"已复习"。它不是简单改个数字，而是走了和 App 里一样的队列引擎——会写复习流水、更新记忆状态、会话计数也跟着走。」 |
| 1:05-1:25 | 打开 App → 进单词列表 → 点该词详情 → 看历史时间线 | 「进 App 验证一下：刚才那个词的复习历史里确实多了一条"想起 / 阶段 0→1"。」 |
| 1:25-1:45 | 返回桌面 → 在 App 里再答一个词 → 立刻回桌面 | 「App 里作答完，组件数字 **1 秒内**就变了——这是写库后主动触发的刷新，不靠 30 分钟的轮询。」 |
| 1:45-2:10 | 打开 App 点「小组件数据自检」 | 「我自己加了一个自检按钮：组件读的是 `observeDueCount`，列表页读的是各词库求和，两条不同查询路径对比，结果必须相等。现在是一致的。」 |
| 2:10-2:35 | 演示空态：把词库清空后回桌面（或说明做法） | 「没有到期词时组件显示"今日已完成 ✓"；一个词库都没有时显示"还没有词库 ＋ 点此导入"，不会傻乎乎显示 0。」 |
| 2:35-2:50 | 点组件整卡 → 直接进复习页 | 「点组件任意空白处，直接进复习页，不需要先过首页。」 |
| 2:50-3:00 | 长按删除组件 → 回到桌面 | 「删除组件不会影响 App 数据；跨天归零由 WorkManager 每天 00:05 处理。」 |

## 三、录制注意事项

| 项 | 说明 |
|---|---|
| 不要露调试信息 | 先关掉「开发者选项」里的指针位置、布局边界 |
| 通知提前关掉 | 避免录制中出现微信/QQ 通知 |
| 语速 | 每 30 秒约 60-70 字，留呼吸空间 |
| 失败重录点 | 「已复习」按钮点击后若数字未变，说明 App 进程被杀——先打开一次 App 再录 |
| 字幕 | 关键结论（如"同一份数据库""1 秒内刷新"）建议后期加字幕强调 |
